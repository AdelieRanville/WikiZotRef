WikiZotRef — Wikipedia references to Zotero citations

Paste an article's wikitext, match its references to your Zotero library, and download a Word file with live Zotero citations. Everything runs in your browser.

Documentation

1Add the article's references to your Zotero library

Every reference you want converted needs to already exist as an item in your Zotero library — this tool only matches and links, it never creates library items. If the article's sources aren't in your library yet, see the Wikipedia guide on adding an article's references to Zotero and Zotero's Zotero and Wikipedia page.

2Load your Zotero library

In Zotero: right-click your library or collection, choose Export, format “CSL JSON”. Then select that file here.

3Paste the wikitext

Use the article's “Edit source” view, so the <ref> tags are visible.

Base URL for internal [[links]], so they become clickable in Word. Leave blank to keep them as plain text. {{Wikidata entity link}} templates are always turned into links to wikidata.org, labelled with the item's name.

4Check the matches

#ReferenceZotero item

After downloading

Open the file in Word, go to the Zotero tab, click Refresh and pick a citation style. Then use “Add/Edit Bibliography” where you want the reference list. References cited in a row are merged into a single Zotero citation; any left unmatched appear in red so you can spot them and insert manually with Zotero's “Add/Edit Citation”.
